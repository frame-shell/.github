<h3 align="center">frameshell</h3>

<p align="center">
  A desktop for CachyOS and Hyprland that looks like a terminal: square frames, one monospace
  font and the same colors in every app.<br>
  <a href="https://frame-shell.github.io">frame-shell.github.io</a>
</p>

```bash
curl -fsSL https://frame-shell.github.io/install.sh | bash
```

That gets the `frame` command; it asks what you want and fetches only that.

| Repo | |
|---|---|
| [cli](https://github.com/frame-shell/cli) | the `frame` command, the six themes |
| [shell](https://github.com/frame-shell/shell) | Quickshell desktop, Hyprland config, wallpapers, login and boot screens |
| [terminal](https://github.com/frame-shell/terminal) | Ghostty, fish, Starship, fastfetch |
| [spotify](https://github.com/frame-shell/spotify) · [discord](https://github.com/frame-shell/discord) · [steam](https://github.com/frame-shell/steam) | themes and the bridges into the shell |
| [zed](https://github.com/frame-shell/zed) · [zen](https://github.com/frame-shell/zen) · [dolphin](https://github.com/frame-shell/dolphin) | themes |
| [keyboard](https://github.com/frame-shell/keyboard) | lighting and keys for the AULA F75, more boards later |
| [frameshell](https://github.com/frame-shell/frameshell) | docs and what to test |

Work in progress: it runs on my machine and still has bugs. Ideas and bugs go to the
[board](https://github.com/orgs/frame-shell/projects/1).
